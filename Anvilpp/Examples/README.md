# Examples and Experiments

These modules are separate from the public results and the main library's
proof chain. Progress and historical conclusions are recorded in `status.md`.

- `AtomicConjunctiveExamples.lean` checks batch selection, residual construction,
  and the active semantic and compiler rules.
- `WeakRefinement*.lean` contains exploratory comparisons and delay examples.
- `Historical/*.lean.txt` preserves the delay examples for the former silent
  conjunctive-commitment rule. These are archived source, not current Lean
  modules or counterexamples for atomic conjunctive communication.
